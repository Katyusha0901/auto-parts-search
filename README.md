# Auto Parts Search — Поиск автозапчастей

Веб-приложение для поиска автозапчастей по артикулу с возможностью выбора производителя, просмотра предложений, аналогов, цен и остатков на складах.

Разработано с использованием **React, Redux Toolkit, Node.js и Express**.

## Онлайн-демонстрация

**[Открыть приложение](https://auto-parts-search-zm6e.onrender.com)**

Приложение опубликовано на платформе Render и доступно для тестирования непосредственно в браузере.

_Примечание: используется бесплатный тариф Render, поэтому после периода неактивности первый запуск может занимать около минуты._

## Функциональность

- Поиск автозапчастей по артикулу.
- Получение списка доступных производителей.
- Выбор производителя и загрузка соответствующих предложений.
- Отображение аналогов автозапчастей.
- Просмотр цен и остатков на складах.
- Разделение основных товаров и аналогов.
- Обработка состояний загрузки, ошибок и отсутствия результатов.
- Сброс предыдущих результатов при новом поиске.
- Адаптивный интерфейс.

## Установка и запуск

### Требования

- Node.js
- npm

### Установка

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/Katyusha0901/auto-parts-search.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd auto-parts-search
   ```

3. Установить зависимости:

   ```bash
   npm install
   ```

4. Запустить приложение:

   ```bash
   npm start
   ```

Команда одновременно запускает React и Express.

После запуска приложение будет доступно по адресам:

- Frontend: http://localhost:5173
- Backend: http://localhost:3001

## Тестовые артикулы

Для проверки работы приложения можно использовать следующие артикулы:

| Артикул   | Производители      |
| --------- | ------------------ |
| `ABC123`  | Bosch, Valeo, MANN |
| `XYZ789`  | Toyota, Denso      |
| `TEST456` | NGK, Bosch         |

Например, при поиске артикула `ABC123` и выборе производителя **Bosch** отобразятся предложения с нескольких складов и аналог от производителя MANN.

## API

Frontend взаимодействует с Express-сервером посредством асинхронных HTTP-запросов.

### GET /api/brands

Получение списка производителей по указанному артикулу.

Пример запроса:

```http
GET /api/brands?article=ABC123
```

### GET /api/offers

Получение предложений и аналогов по выбранному артикулу и производителю.

Пример запроса:

```http
GET /api/offers?article=ABC123&brand=Bosch
```

Оба маршрута возвращают данные в формате JSON.

## Архитектура приложения

Приложение построено на клиент-серверной архитектуре.

- **React** отвечает за пользовательский интерфейс и взаимодействие с пользователем.
- **Redux Toolkit** управляет состоянием поиска, выбранным производителем, предложениями, загрузкой и ошибками.
- **Express** обрабатывает HTTP-запросы и предоставляет API-маршруты.
- **Функции преобразования данных** обрабатывают ответы API и приводят их к формату, необходимому для отображения производителей, предложений и аналогов.

Frontend и backend разрабатываются как отдельные части приложения, но развёрнуты на Render в рамках одного веб-сервиса.

## Интеграция с Favorit Parts API

Приложение разработано с учётом [документации Favorit Parts API](https://lk.favorit-parts.ru/static/wsprice.pdf).

Поскольку API-ключ не был предоставлен, Express-сервер использует демонстрационные данные, структура которых адаптирована под соответствующие поля API.

При этом взаимодействие между frontend и backend реализовано через настоящие HTTP-запросы.

**Интеграция с внешним API Favorit Parts не тестировалась из-за отсутствия доступа.**

Такой подход позволяет продемонстрировать работу поиска, клиент-серверное взаимодействие, управление состоянием и обработку данных без использования внешнего API-ключа.

## Production-сборка

Для создания production-сборки frontend выполнить:

```bash
npm run build
```

Для запуска Express-сервера:

```bash
npm run server
```

Express раздаёт собранное React-приложение из папки `dist` и обрабатывает API-запросы.

После запуска production-версия будет доступна по адресу http://localhost:3001.
